# MATLAB Numerical Methods

A collection of MATLAB-based computational engineering exercises focused on numerical methods, finite-difference approximations, iterative solvers, heat conduction, and numerical error analysis.

## Projects

### 1. 2D Heat Conduction

Numerical solution of steady and unsteady two-dimensional heat conduction problems.

The work includes:

- steady-state 2D heat conduction
- transient 2D heat conduction
- explicit and implicit formulations
- Jacobi iterative method
- Gauss-Seidel iterative method
- Successive Over-Relaxation (SOR)
- convergence based on an absolute-error criterion
- temperature-field visualization

For the investigated implicit cases, the iterative methods are compared based on convergence behavior and number of iterations.

### 2. Fourth-Order Finite-Difference Approximation

Derivation and numerical evaluation of fourth-order approximations for a second derivative using the Taylor-table method.

The work investigates:

- central finite-difference approximation
- right-sided skewed approximation
- left-sided skewed approximation
- derivation of finite-difference coefficients
- MATLAB implementation
- comparison with an analytical derivative
- absolute-error analysis for different grid spacings

The study illustrates why central differencing can provide lower error while one-sided/skewed schemes are useful near boundaries where data are not available on both sides of a point.
